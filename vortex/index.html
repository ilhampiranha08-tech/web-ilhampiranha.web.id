01 // CORE SYSTEM CAPABILITIES

6 Core Pillars of Vortex

⚡

Super Fast Explorer with Dual Pane

Simultaneous side-by-side navigation across two folders or storage devices. Moving heavy files, comparing directories, and organizing archives is instant without switching apps.

🔒

AES-256 Safe Folder Encryption

Hardware-backed symmetric AES-256-GCM encrypted vault. Cryptographic keys are protected directly by the Android Hardware Keystore chip. Document and photo privacy is 100% fortified at the silicon level.

📡

WebDAV/FTP Server & P2P Near-Drop

Transform your smartphone into a local wireless file server. Manage and download your phone's files from any PC or laptop browser without cables. Includes instant peer-to-peer Wi-Fi Direct Near-Drop transfers.

🌐

SMB / FTP / SFTP / WebDAV Client

All-in-one network client. Connect seamlessly to personal NAS (Network Attached Storage), Windows network shares (SMB), remote Linux servers over encrypted SSH (SFTP), and cloud WebDAV servers.

📝

Text Editor with Undo/Redo

Lightweight yet capable built-in code and text editor. Features line numbering, unlimited Undo & Redo, rapid text search, and multi-format support for inspecting and modifying scripts on the fly.

🧹

Storage Analyzer & Smart Clean-Up

Interactive visual breakdown of internal storage and SD card capacity. Accurately pinpoints bulky space-hogging files, leftover cache, and duplicate files to keep your device clutter-free.

02 // ARCHITECTURE & ENGINEERING

Engineered for Velocity, Security & Zero Ads

Vortex is not just another file explorer. Built from the ground up by Ilham Sugiri with the uncompromising robustness of Linux on modern Android devices.

  • ✔
    Modular Virtual File System (VFS): Abstracts Local Storage, SAF, USB OTG, NAS SMB, FTP, SFTP, and WebDAV into a unified high-throughput I/O pipeline.
  • ✔
    Zero-Telemetry & 100% Ad-Free: No ad SDKs, no behavioral trackers, no invasive analytics, and no third-party relay proxies. All network traffic flows strictly peer-to-peer.
  • ✔
    Reactive Kotlin Coroutines & Jetpack Compose: Next-gen user interface rendering at a smooth 120Hz with zero UI freezing when indexing massive filesystem trees.
  • ✔
    Secure Cloud OAuth Integration: Google Drive support utilizing official token authorization without storing user credentials.
